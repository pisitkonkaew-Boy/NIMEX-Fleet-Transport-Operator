# NIMEX Fleet Transport Operator

รายได้ ค่าใช้จ่าย และกำไร/ขาดทุนของรถผู้ประกอบการขนส่ง ราย DC และรายทะเบียน หน้าตาตาม NIMEX Design Kit
หน้าเว็บอ่านข้อมูลจาก Google Sheet ผ่าน Apps Script — **repo นี้ไม่มีตัวเลขจริง** ห้ามนำ fto-seed.json หรือไฟล์ Excel ขึ้น repo

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| index.html | หน้าแดชบอร์ด (การคำนวณเหมือนเดิมทุกอย่าง) |
| config.js | ที่อยู่ Apps Script (`FTO_API`) และเลขเวอร์ชัน (`FTO_V`) |
| boot.js | โหลดข้อมูลจาก Sheet, ตรวจรหัสผู้ดูแล, นำเข้าครั้งแรก, บันทึกไฟล์ที่อัปโหลด |
| Code.gs.txt | โค้ดฝั่ง Apps Script |
| logo.png / cover.jpg | โลโก้ และหน้าปก (ใช้เป็นรูปตัวอย่างลิงก์ใน LINE) |

## ติดตั้งครั้งแรก
1. สร้าง Google Sheet ใหม่ → Extensions > Apps Script → วางเนื้อหา `Code.gs.txt` บันทึกเป็น Code.gs
2. Project Settings > Script Properties → เพิ่ม `ADMIN_KEY` = รหัสผู้ดูแล
3. Deploy > New deployment > Web app > Execute as: **Me**, Who has access: **Anyone** → คัดลอก URL ที่ลงท้าย `/exec`
4. แก้ `config.js` ใส่ URL ที่ `FTO_API` แล้วอัปโหลดไฟล์ทั้งหมดขึ้น repo
5. เปิดลิงก์เว็บต่อท้าย `#admin` → ใส่รหัส → หน้า "ตั้งค่าครั้งแรก" → เลือกไฟล์ `fto-seed.json` → ระบบบันทึกลง Sheet

## ใช้งาน
- ผู้ชมทั่วไป: เปิดลิงก์ปกติ ดูได้อย่างเดียว ไม่เห็นปุ่มนำเข้าและส่งออก
- ผู้ดูแล: เปิดลิงก์ต่อท้าย `#admin` → กด "นำเข้าข้อมูล" → ระบบสรุป เพิ่มใหม่ / แทนที่ ให้ตรวจก่อนบันทึก (ทะเบียน + DC ซ้ำ ยึดค่าใหม่)
- แก้หน้าเว็บแล้วผู้ชมยังเห็นของเก่า ให้เพิ่มเลข `FTO_V` ใน config.js

## ความเป็นส่วนตัว
repo เป็นสาธารณะ และ Apps Script เปิดให้ทุกคนที่มีลิงก์อ่านได้ ใครมีลิงก์เว็บก็เห็นข้อมูลบนแดชบอร์ด (รวมชื่อเจ้าของรถในหน้ารายละเอียด)
